# Шаблон блока «Настройки радара»

Выведи этот блок в конце первой настройки и после любых изменений. Пользователь сохраняет
его один раз: в инструкции проекта, в текст задачи по расписанию или у себя в заметках.
Ключи, ссылки вебхука и пароли сюда не пиши — только «есть, лежит в инструкции проекта».

```text
Настройки радара
- Часовой пояс: {например, Екатеринбург, UTC+5}
- Время сводки: {08:00, по будням} · Расписание: {ChatGPT / Claude Cowork / вручную «радар»}
- Почта: {Gmail через коннектор / Outlook / вручную}
- Календарь: {Google Calendar через коннектор / Битрикс24 по ссылке / вручную}
- Задачи: {Битрикс24 по ссылке, где я исполнитель / вручную / нет}
- Ссылки Битрикс24: {есть, лежат в инструкции проекта / нет}
- Важные отправители: {адреса или домены}
- Важные слова в теме: {счёт, договор, срочно}
- Окно почты: {7} дн. · «Ответить» — письма без ответа дольше: {4} ч
```
